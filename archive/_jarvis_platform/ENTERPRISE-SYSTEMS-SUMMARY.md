## 🎯 Use Case Examples

### **1. Canary Deployment with Full Monitoring**

```javascript
import { MasterOrchestrator } from './master-orchestrator.js';

const master = new MasterOrchestrator();

// Create feature flag for new version
master.createFeatureFlag('api-v2', {
  enabled: true,
  defaultValue: false
});

// Start gradual rollout with monitoring
const rollout = master.startGradualRollout('api-v2', {
  stages: [5, 10, 25, 50, 100],
  stageInterval: 3600000, // 1 hour
  safetyThreshold: 0.02 // 2% error rate max
});

// System automatically:
// - Monitors error rates
// - Collects traces
// - Rolls back if unsafe
// - Heals issues if detected
```

### **2. Chaos Testing with Auto-Recovery**

```javascript
// Register chaos experiment
await master.runChaosExperiment('latency-spike', mockWorkload, {
  type: CHAOS_TYPES.LATENCY,
  parameters: { delay: 1000, jitter: 500 },
  duration: 120000,
  rolloutPercentage: 25
});

// System automatically:
// - Runs experiment safely
// - Monitors system health
// - Aborts if thresholds exceeded
// - Triggers auto-healing if needed
// - Calculates resilience score
```

### **3. Service Mesh with Full Observability**

```javascript
// Make request through mesh
const result = await master.meshRequest('user-service', async (instance) => {
  return await getUserData(instance);
}, { userId: '123' });

// System automatically:
// - Selects best instance (load balancing)
// - Applies circuit breaking
// - Retries on failure
// - Traces request
// - Collects metrics
// - Logs all events
```
