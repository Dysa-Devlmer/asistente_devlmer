# 🚀 Instrucciones para Crear GitHub Release v2.0.1

## Pasos para Crear el Release en GitHub

### 1. Ve a tu repositorio
```
https://github.com/Soyelijah/jarvis-mark-vii
```

### 2. Click en "Releases" (en el sidebar derecho)

### 3. Click en "Create a new release"

### 4. Selecciona el tag **v2.0.1** del dropdown

### 5. Título del Release:
```
🚀 JARVIS v2.0.1 - Professional Repository Release
```

### Option 1: Quick Demo
```bash

npm install

```

### Option 2: Full System

### Option 3: Docker
