## 🚀 Próximos Pasos Recomendados

### Paso 1: Instalar Ollama (Si no lo tienes)

**Windows:**
```bash
# Descargar de: https://ollama.com/download/windows
# Luego:
ollama pull qwen2.5-coder:latest
```

**Linux/Mac:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5-coder:latest
```

### Paso 2: Iniciar Ollama

```bash
# En una terminal separada (déjala corriendo):
ollama serve
```

### Paso 3: Probar JARVIS

```bash
# En otra terminal:
npm run jarvis
```

**Comandos para probar:**

```bash
# 1. Ver ayuda
JARVIS> help

# 2. Ver estado
JARVIS> status

# 3. Aprender algo
JARVIS> learn Node.js best practices

# 4. Tarea autónoma simple
JARVIS> autonomous Crear un validador de email simple con tests

# 5. Ver estadísticas
JARVIS> stats

# 6. Salir
JARVIS> exit
```
