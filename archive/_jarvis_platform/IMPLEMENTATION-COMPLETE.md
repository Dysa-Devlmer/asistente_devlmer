3. Clic en **"Test AI"**
4. Observar:
   - Live events actualizándose
   - Recent interactions agregándose
   - Stats cards incrementando
   - Patterns actualizándose

### Test de API REST:

```bash
# Test interact endpoint
curl -X POST http://localhost:7777/api/ai/interact \
  -H "Content-Type: application/json" \
  -d '{
    "input": "¿Cómo optimizar mi aplicación?",
    "context": {
      "domain": "code",
      "taskType": "analysis",
      "urgency": 0.7
    }
  }'

# Test status endpoint
curl http://localhost:7777/api/ai/status

# Test insights endpoint
curl http://localhost:7777/api/ai/insights
```

### Test de WebSocket:

Abrir consola del navegador en `http://localhost:5173` y ejecutar:

```javascript
// Conectar
const socket = io('http://localhost:7777');

// Solicitar estadísticas
socket.emit('ai:request:stats');

// Escuchar respuesta
socket.on('ai:stats', (data) => {
  console.log('AI Stats:', data);
});

// Interactuar con IA
socket.emit('ai:interact', {
  input: 'Crear una nueva función',
  context: { domain: 'code' }
});

socket.on('ai:interaction:result', (result) => {
  console.log('Result:', result);
});
```
