## Upgrade Guide

### From v1.0.0 to v2.0.0

1. **Backup your data:**
   ```bash
   cp -r memory memory-backup
   ```

2. **Pull latest changes:**
   ```bash
   git pull origin master
   ```

3. **Install new dependencies:**
   ```bash
   npm install
   ```

4. **Update configuration:**
   - Backend now runs on port 7777 (update any scripts)
   - New environment variables may be needed (check `.env.example`)

5. **Run migration script** (if applicable):
   ```bash
   npm run migrate
   ```

6. **Test the system:**
   ```bash
   npm run demo:auto
   ```
